माझी डेअरी — Firestore Security Rules

Firebase Console → Firestore Database → Rules मध्ये हे rules paste करा आणि Publish करा:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

यामुळे login केलेला शेतकरी फक्त स्वतःच्या users/{uid}/... data ला access करू शकतो.
